# CodeNest

CodeNest is a web-based 2D adventure game designed to help STI MAWD students learn Java programming through structured lessons, interactive assessments, and RPG-inspired gameplay.

## Project Overview

CodeNest combines Java programming education with gamification. Students progress through a structured Java learning path while completing lessons, answering programming questions, participating in challenges, earning XP, and advancing through the game.

The project focuses specifically on Java instead of attempting to cover multiple programming languages. This keeps the learning experience focused and allows the system to provide more structured and meaningful Java programming activities.

## Target Users

CodeNest is designed primarily for STI Mobile App and Web Development (MAWD) students learning Java programming.

## Core Features

- User registration and login
- RPG-style dashboard
- Structured Java learning path
- Java lessons
- Interactive Java assessments
- PvE programming challenges
- XP and leveling system
- Player progress tracking
- Leaderboard
- Story/adventure progression

## Technology Stack

- PHP
- MySQL / MariaDB
- HTML
- CSS
- JavaScript
- XAMPP
- Git / GitHub

Java is the **subject being taught by the system**, while the CodeNest web application itself is built primarily with PHP, JavaScript, HTML, CSS, and MySQL.

## Running the Project

1. Install XAMPP.
2. Start Apache and MySQL.
3. Place the project in:

   `C:\xampp\htdocs\codenest`

4. Import the CodeNest database through phpMyAdmin.
5. Open:

   `http://localhost/codenest/`
